Bulk create feedback forms

Create one form per teaching session in a single action. Define the questions once, choose which sessions to target, and the system generates a separate, correctly-scoped form for each subject/teacher/period — so results stay separated per class period.

Step 1 · Which sessions?

Leave a filter on “All” to include everything. Sessions that already have a form are automatically skipped, so this is safe to run repeatedly.

Step 2 · Title & availability
Placeholders: {subject} {subject_code} {teacher} {period} {timetable} {branch} {semester}
Step 3 · Question template

These questions are applied to every generated form. Each form keeps its own copy.

Cancel

Nothing is created until you click Generate forms.
